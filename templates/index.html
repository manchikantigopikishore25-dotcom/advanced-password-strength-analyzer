06

Cybersecurity Educational Guide

Key cryptographic concepts, attack vectors, and NIST SP 800-63B standards explained.

🧮

Password Entropy

Entropy measures the theoretical unpredictability of a password in bits. Calculated via H = L × log₂(R), where L is length and R is character pool size. Every extra bit doubles the search combinations required for brute-force cracking.

⚔️

Brute-Force vs. Dictionary

Brute-Force systematically traverses every possible permutation in a character set. Dictionary Attacks test pre-compiled lists of billions of breached words combined with permutation rules (mangling).

🔁

Credential Stuffing & Reuse

When a service suffers a database breach, automated threat bots test those username/password pairs against thousands of other websites. Reusing passwords guarantees multi-platform compromise upon a single leak.

📜

NIST SP 800-63B Guidelines

Modern NIST standards discourage arbitrary periodic password expiration and rigid composition rules (which cause predictable substitutions like P@ssw0rd1!). Instead, NIST emphasizes length (16+ chars), multi-word passphrases, and blocklist checking.

🔐

Analysis vs. Storage (Argon2 / bcrypt)

Password Analysis evaluates credential complexity in transient volatile memory. Secure Storage requires one-way, salted, slow cryptographic Key Derivation Functions (KDFs) like Argon2id or bcrypt to defeat GPU cracking clusters.

📱

MFA & Password Managers

A password manager (e.g., Bitwarden, 1Password) produces unique 20+ character passwords for every account. Multi-Factor Authentication (MFA / 2FA via authenticator apps or FIDO2 hardware keys) stops 99.9% of automated account takeovers.
